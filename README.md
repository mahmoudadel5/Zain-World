# عالم زين التعليمي — Zain's Learning World 🌟

موقع تعليمي تفاعلي للأطفال (بدون أي مكتبات أو إنترنت — ملفات HTML/CSS/JS فقط).

## المحتوى
**التعلّم:** الحروف العربية والإنجليزية • الأرقام العربية والإنجليزية • الألوان ومختبر الخلط • الأشكال • العلوم (فواكه، خضروات، حيوانات، طبيعة، جسمي، الطقس، النباتات) • مشاعري • حكايات قصيرة مع أسئلة • اسمي (تتبّع وترتيب حروف «زين / ZAIN»)

**ألعاب الذكاء (٣٠+ لعبة):**
- 🧩 ألغاز وبناء: الأحجية، قلّد البرج، ابنِ برجك
- 🧠 ذاكرة وانتباه: لعبة الذاكرة، التقط النجوم
- 🔷 تصنيف وأنماط: نمط الأرقام والألوان، صنّف الأشكال، أكبر وأصغر وأكثر، فوق وتحت وداخل
- 🤖 تفكير وبرمجة: الروبوت الذكي (أوامر الاتجاهات)، رتّب الخطوات (روتين يومي وسلامة)
- 🔤🔢🎨 الحروف والأعداد والألوان والعلوم والمشاعر والسلوك (ماذا نقول؟ ماذا نفعل؟)

**ألعاب الحركة:** سيمون يقول، قف وتحرّك، ابحث عن شيء (مستكشف البيت)

**أخرى:** رسم وتلوين مع حفظ الصورة، نجوم وشهادة «Super Star Zain»

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub، مثلًا `zain-world`.
2. ارفع **محتويات** هذا المجلد (index.html و style.css و app.js ومجلد fonts) إلى الفرع `main`.
3. من **Settings ← Pages** اختر: Source = *Deploy from a branch*، Branch = `main`، Folder = `/ (root)` ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/zain-world/`

> النطق الصوتي يستخدم أصوات الجهاز (Web Speech). على بعض الأجهزة قد لا يتوفر صوت عربي — ثبّت صوتًا عربيًا من إعدادات النظام.
> النجوم محفوظة في متصفح الجهاز فقط.
