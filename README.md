# عالم زين التعليمي — Zain's Learning World 🌟

موقع تعليمي تفاعلي للأطفال (بدون أي مكتبات أو إنترنت — ملفات HTML/CSS/JS فقط).

## المحتوى
- 🔤 الحروف العربية (أ → ي) والحروف الإنجليزية (A → Z): صوت، كلمة وصورة، وتتبّع الحرف بالإصبع
- 🔢 الأرقام العربية ٠–١٠ والإنجليزية 0–10: عدّ تفاعلي ونطق وكتابة
- 🎨 الألوان + مختبر لخلط الألوان
- 🔬 العلوم: فواكه، خضروات، حيوانات، الطبيعة
- 🎮 ١٢ لعبة: اختر الحرف، كم العدد، فرقع البالونة، أكمل النمط، ألوان، فاكهة أم خضار، لعبة الذاكرة
- 🖍️ لوحة رسم مع حفظ الصورة، ونجوم وشهادة «Super Star Zain»

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub، مثلًا `zain-world`.
2. ارفع **محتويات** هذا المجلد (index.html و style.css و app.js ومجلد fonts) إلى الفرع `main`.
3. من **Settings ← Pages** اختر: Source = *Deploy from a branch*، Branch = `main`، Folder = `/ (root)` ثم Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/zain-world/`

> النطق الصوتي يستخدم أصوات الجهاز (Web Speech). على بعض الأجهزة قد لا يتوفر صوت عربي — ثبّت صوتًا عربيًا من إعدادات النظام.
> النجوم محفوظة في متصفح الجهاز فقط.
